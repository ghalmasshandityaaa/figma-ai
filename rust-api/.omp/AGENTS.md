# Second Brain Link

This project's second-brain context — daily work journal, kanban tickets (Backlog → In
Progress → Review → Done → Cancelled), architecture decisions, and tech-stack notes —
lives outside this repo, at:

`/mnt/d/knowledges/ai context/Projects/rust-api/`

Read `Overview.md` there before starting work here. Log today's context and keep kanban
tickets current in that folder as you go — full workflow rules:
`/mnt/d/knowledges/AGENTS.md` (or the portable skill at
`/mnt/d/knowledges/.agents/skills/obsidian-second-brain/`, installable into this repo's
own `.agents/skills/` if you want it discovered without the absolute-path pointer).

This file is intentionally minimal — it exists so any omp session opened directly in this
repo (rather than in the vault) still finds its way back to that context automatically,
without needing to be told.
